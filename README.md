# Password Manager v2.0

Приложение для безопасного хранения паролей и учётных данных с шифрованием. Все чувствительные данные шифруются одним мастер-ключом и доступны только после его ввода.

**Основные возможности:**

- Добавление, редактирование и удаление записей паролей
- Шифрование всех чувствительных полей одним мастер-ключом
- Группы записей с автодополнением
- Поиск по записям
- Импорт и экспорт паролей в JSON
- Одностраничный веб-интерфейс
- Автоматическое открытие браузера при запуске
- Иконка в системном трее с пунктами «Открыть в браузере» и «Выход»
- Сборка в один EXE-файл без консольного окна (PyInstaller)

## Система шифрования

### Обзор

Приложение использует **SHA-256-CTR + HMAC-SHA256** для защиты чувствительных данных:
- Записи в менеджере паролей `passwords.json` (название, логин, пароль, почта, группа, комментарий)

### Ключевые особенности

1. **Один мастер-ключ** — пользователь запоминает один ключ для доступа ко всем данным
2. **Усиление ключа** — PBKDF2-HMAC-SHA256 с 600,000 итераций и уникальной для проекта солью
3. **Разделение ключей** — из мастер-ключа выводятся два подключа: для шифрования и для HMAC
4. **Аутентификация** — HMAC-SHA256 для защиты от подделки данных (проверяется до дешифрования)
5. **Уникальность шифротекстов** — случайный nonce (16 байт) для каждого шифрования
6. **Без внешних библиотек** — только `hashlib`, `hmac`, `os` из стандартной библиотеки Python

### Формат зашифрованных данных

```
secure:<base64(nonce + hmac + ciphertext)>
```

Где:
- `nonce` — 16 байт случайных данных (уникален для каждого шифрования)
- `hmac` — 32 байта HMAC-SHA256(mac_key, nonce + ciphertext)
- `ciphertext` — данные, зашифрованные SHA-256-CTR (XOR с keystream)

### Соль PBKDF2

В `app/crypto.py` используется фиксированная соль проекта. Она **не является секретом** — её задача
сделать радужные таблицы бесполезными для данного приложения. Соль нельзя менять без перешифровки
`passwords.json`: иначе существующие записи перестанут расшифровываться.

### Использование в API

Ключ передается через заголовок `X-Encrypt-Key`:
```http
GET /api/passwords
X-Encrypt-Key: ваш_мастер_ключ
```

Без ключа возвращаются зашифрованные значения. С ключом — расшифрованные данные.
Ключ хранится только в памяти JavaScript (в переменной), не в sessionStorage/localStorage,
и сбрасывается при обновлении страницы.

## Группы

Группа — это необязательное текстовое поле записи. Список существующих групп собирается из самих
записей и предлагается в поле «Группа» через автодополнение (`datalist`). Отдельного файла групп нет.

## Установка и запуск

### Локальный запуск (разработка)

```bash
pip install -r requirements.txt
python run.py
```

При запуске браузер открывается автоматически на `http://127.0.0.1:8062/`,
а в системном трее появляется значок 🔑.

### Значок в системном трее

Пока приложение работает, в трее (рядом с часами) отображается иконка:

- **клик левой кнопкой** — открыть интерфейс в браузере;
- **клик правой кнопкой** — меню «Открыть в браузере» / «Выход».

Пункт «Выход» корректно останавливает сервер и убирает значок.
Закрытие вкладки браузера приложение не завершает — оно продолжает работать в трее.

Трей реализован в `app/tray.py` на `ctypes` (Win32 API), без сторонних библиотек.
На других ОС приложение просто работает как обычный локальный сервер.

### Альтернативный запуск

```bash
uvicorn run:app --host 127.0.0.1 --port 8062 --reload
```

В этом режиме браузер автоматически не открывается и значок в трее не создаётся —
перейдите на `http://127.0.0.1:8062/` вручную.

### Сборка EXE (Windows)

Самый простой способ — запустить `build.bat`. Скрипт создаст/использует `.venv`, установит
PyInstaller и соберёт один файл `dist/PasswordManager.exe` со встроенным фронтендом и иконками.
Сборка идёт с ключом `--noconsole`, поэтому консольное окно не открывается.

Эквивалентная команда вручную:

```powershell
pyinstaller --noconfirm --clean --onefile --noconsole --name PasswordManager `
  --icon "assets/icon.ico" `
  --add-data "static;static" `
  --add-data "assets;assets" `
  --collect-submodules uvicorn `
  run.py
```

`passwords.json` и `password_manager.log` намеренно не упаковываются в EXE: при первом запуске
они создаются рядом с `PasswordManager.exe`, чтобы данные можно было редактировать и резервировать.
Лог помогает диагностировать проблемы, когда консольного окна нет.

Если порт `8062` уже занят (например, приложение уже запущено), появится окно с сообщением об этом.

Иконка для EXE и favicon генерируются скриптом `python tools/make_icon.py` (без сторонних библиотек).

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/` | Главная страница (возвращает `index.html`) |

## Использование

1. Запустить приложение (`python run.py` или `PasswordManager.exe`)
2. Ввести мастер-ключ в открывшемся окне
3. Добавлять, редактировать и удалять записи в таблице
4. Указывать группу прямо в записи — существующие группы предлагаются автоматически
5. Использовать поиск и импорт/экспорт JSON для резервного копирования

### Формат JSON для импорта

При нажатии «📂 Загрузить из JSON» интерфейс показывает подсказку с форматом файла.
Файл — массив объектов; обязательное поле только `name`:

```json
[
  {
    "name": "GitHub",
    "login": "user",
    "password": "secret",
    "email": "user@example.com",
    "comment": "рабочий аккаунт",
    "group": "Работа"
  }
]
```

Такой же формат создаёт кнопка «💾 Выгрузить в JSON». Импорт **заменяет** все текущие записи.

## Безопасность

- Все чувствительные данные шифруются одним мастер-ключом
- **SHA-256-CTR + HMAC-SHA256** — современная конструкция на основе стандартной библиотеки Python
- **PBKDF2 усиление ключа (600,000 итераций)** — замедляет офлайн-брутфорс в 12 раз по сравнению
  с предыдущей версией (50,000 итераций)
- **Фиксированная соль PBKDF2** — предотвращает предвычисленные радужные таблицы
- **Разделение ключей** — разные ключи для шифрования и аутентификации
- **HMAC проверяется до дешифрования** — защита от oracle-атак
- **Ключ хранится только в памяти JavaScript** (переменная), не в sessionStorage/localStorage,
  сбрасывается при обновлении страницы
- **Сервер слушает только `127.0.0.1`** — приложение недоступно из локальной сети
- Для удалённого доступа используйте HTTPS через reverse proxy

### Почему SHA-256-CTR, а не AES?

`hashlib` и `hmac` — единственные криптографические модули в стандартной библиотеке Python, которые
не требуют установки внешних пакетов. Конструкция SHA-256-CTR (SHA-256 в режиме счётчика) —
это стандартный подход к созданию stream cipher на основе криптографической хеш-функции.
SHA-256 считается безопасной PRF (псевдослучайной функцией), поэтому SHA-256-CTR даёт
криптостойкий keystream.
