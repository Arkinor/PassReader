📂 Формат JSON для импорта

Файл должен содержать массив объектов. Обязательное поле — name, остальные можно не указывать. Такой же файл создаёт кнопка «💾 Выгрузить в JSON». 

[
  {
    "name": "GitHub",
    "login": "user",
    "password": "secret",
    "email": "user@example.com",
    "comment": "рабочий аккаунт",
    "group": "Работа"
  }
]

name — название, login — логин, password — пароль, email — почта, comment — примечание, group — группа.

⚠ Импорт заменяет все текущие записи.
